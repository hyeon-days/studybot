# study-bot

정기 알림과 음성채널 공부시간 리더보드를 **디스코드 안에서 명령어로** 설정하는 스터디봇입니다. 별도 대시보드나 설정 파일 수정 없이, 시간, 문구, 채널을 모두 슬래시 명령어로 바꿉니다. 모든 시간은 KST 기준입니다.

## 기능

- **정기 메시지:** 정해진 시각에 정해진 채널로 문구를 올립니다. 처음 설치하면 `목표`(10:00, `[{날짜}] 오늘의 목표를 설정해주세요!`)와 `진행체크`(18:00, `[{날짜}] 진행 상황을 체크해주세요!`)가 만들어져 있고, 채널만 지정하면 바로 동작합니다. `{날짜}`는 `26/10/27`처럼 YY/MM/DD로, `{요일}`은 `월`~`일`로 바뀝니다.
- **공부시간 측정:** 지정한 음성채널에 머문 시간을 사람별로 합산합니다. 카메라나 화면공유 여부는 따지지 않고, 봇 계정은 제외합니다.
- **리더보드:** `1위 철수 · 3시간 20분` 형식으로 순위를 보여 줍니다. 명령어로 바로 볼 수도 있고, 정해진 시각에 자동으로 올릴 수도 있습니다(기본 알림 `오늘랭킹`, 23:59).

## 명령어

`/알림`과 `/공부채널`은 **서버 관리 권한**이 있는 사람만 보입니다. 서버 설정 > 연동 > 봇에서 특정 역할에 따로 허용할 수도 있습니다.

| 명령어 | 설명 |
| --- | --- |
| `/알림 목록` | 등록된 알림과 다음 게시 시각을 봅니다 |
| `/알림 추가 이름 시간 채널 [요일]` | 새 정기 메시지를 만듭니다. 문구는 이어서 뜨는 입력창에 씁니다(줄바꿈 가능) |
| `/알림 리더보드추가 이름 시간 채널 기간 [요일]` | 리더보드 자동 게시를 만듭니다 |
| `/알림 수정 이름 [시간] [채널] [요일] [기간]` | 입력한 항목만 바꿉니다 |
| `/알림 문구 이름` | 문구(리더보드는 제목)를 입력창에서 고칩니다 |
| `/알림 켜기·끄기 이름` | 지우지 않고 잠시 멈추거나 다시 켭니다 |
| `/알림 삭제 이름` | 알림을 지웁니다 |
| `/알림 지금보내기 이름` | 지정 채널에 지금 한 번 보내 봅니다(정기 일정에는 영향 없음) |
| `/공부채널 추가·제거 채널` | 공부시간을 잴 음성채널을 지정하거나 뺍니다. 여러 개 지정할 수 있습니다 |
| `/공부채널 목록` | 지정된 음성채널을 봅니다 |
| `/리더보드 [기간]` | 누구나 사용. 순위를 채널에 올립니다(기본: 오늘) |
| `/내공부시간` | 누구나 사용. 오늘, 이번 주, 이번 달, 전체 기록과 순위를 나에게만 보여 줍니다 |

시간은 `10:00`, `1000`, `10시`, `18시 30분` 모두 됩니다. 요일은 `매일`(기본), `평일`, `주말`, `월수금`, `일`처럼 씁니다. 기간은 오늘, 어제, 이번 주, 지난 주, 이번 달, 전체 중에서 고르고, 한 주는 월요일에 시작합니다.

### 설치 직후 할 일

```
/공부채널 추가 채널:#스터디룸
/알림 수정 이름:목표 채널:#오늘의-목표
/알림 수정 이름:진행체크 채널:#오늘의-목표
/알림 수정 이름:오늘랭킹 채널:#리더보드
/알림 지금보내기 이름:목표        ← 잘 나오는지 확인
```

주간 랭킹을 일요일 밤에 따로 올리고 싶다면 이렇게 추가합니다.

```
/알림 리더보드추가 이름:주간랭킹 시간:23:59 채널:#리더보드 기간:이번 주 요일:일
```

### 알아 둘 동작

- 시간이나 요일을 바꾸면 **지금 이후의 예정 시각부터** 적용됩니다. 10:05에 시간을 10:00으로 바꾸면 내일 10:00부터 올라갑니다.
- 봇이 재시작되느라 예정 시각을 놓쳐도 10분 안에 다시 켜지면 늦게라도 보냅니다. 그보다 늦으면 그날은 건너뜁니다.
- 봇이 꺼진 동안의 음성채널 체류는 기록되지 않습니다. 비정상 종료 시에는 마지막 확인 시각(1분 간격)까지만 인정하고, 다시 켜질 때 채널에 있는 사람부터 다시 셉니다.
- 문구에 역할 멘션을 넣으려면 `<@&역할ID>`, 전체 멘션은 `@everyone`을 씁니다. `@everyone`이 실제로 알림을 보내려면 봇에게 '@everyone 멘션' 권한이 있어야 합니다.

## 설치

### 1. 디스코드 봇 만들기

1. [Discord Developer Portal](https://discord.com/developers/applications)에서 New Application을 만듭니다.
2. Bot 탭에서 Reset Token으로 토큰을 받아 둡니다. 이 봇은 특권 인텐트(Server Members, Message Content)가 필요 없으므로 따로 켤 것은 없습니다.
3. 아래 주소의 `APP_ID`를 General Information의 Application ID로 바꿔 열고, 스터디 서버에 초대합니다. 채널 보기, 메시지 보내기, 링크 첨부 권한이 포함되어 있습니다.

```
https://discord.com/oauth2/authorize?client_id=APP_ID&scope=bot+applications.commands&permissions=19456
```

`@everyone` 멘션까지 쓰려면 `permissions=150528`로 초대합니다.

### 2. 서버에서 실행하기

Node.js 20.6 이상이 필요합니다. 봇은 24시간 켜져 있어야 하므로 Oracle Cloud 무료 인스턴스, 소형 VPS, 상시 켜 두는 PC 등에서 실행합니다.

```bash
git clone <이 저장소 주소> study-bot && cd study-bot
npm ci
cp .env.example .env   # DISCORD_TOKEN 입력
npm run build
npm start
```

`Ready! Logged in as ...`가 뜨면 서버에 슬래시 명령어가 바로 등록됩니다. 디스코드 앱에서 명령어가 안 보이면 Ctrl+R로 새로고침합니다.

계속 켜 두려면 pm2를 씁니다.

```bash
npm install -g pm2
pm2 start dist/index.js --name study-bot --node-args="--env-file=.env"
pm2 save && pm2 startup   # 서버 재부팅 후 자동 실행
```

코드를 업데이트할 때는 `git pull && npm ci && npm run build && pm2 restart study-bot`입니다.

데이터는 `data/bot.sqlite` 파일 하나에 저장됩니다. 백업은 이 파일을 복사하면 됩니다.

| 파일 | 역할 |
| --- | --- |
| `src/index.ts` | 봇 시작, 이벤트 연결, 서버별 명령어 등록 |
| `src/commands.ts` | 슬래시 명령어 정의와 처리 |
| `src/scheduler.ts` | 20초마다 예정된 알림을 확인해 게시 |
| `src/voice.ts` | 음성채널 입장, 퇴장 기록 |
| `src/leaderboard.ts` | 순위 계산과 임베드 생성 |
| `src/store.ts` | SQLite 저장소 |
| `src/time.ts` | KST 날짜 계산, 시간/요일 파싱 |
